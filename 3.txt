// промпт на создание руководства пользователя 
--------------------------------------------------------------------------------------

Ты помогаешь составить «Руководство пользователя» по ГОСТ 19.505-79
для квалификационного экзамена по ПМ.04 «Сопровождение и обслуживание
программного обеспечения» (спец. 09.02.07).

ПРОГРАММА, для которой нужно написать руководство:
[НАЗВАНИЕ ПРОГРАММЫ И ВЕРСИЯ]

ТЕКСТ ЗАДАНИЯ ИЗ БИЛЕТА (вставьте текст задания сюда):
(пусто)

ГОСТ 19.505-79 в актуальной редакции для полного руководства пользователя
требует 6 разделов:
1) ВВЕДЕНИЕ;
2) НАЗНАЧИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ;
3) ПОДГОТОВКА К РАБОТЕ;
4) ОПИСАНИЕ ОПЕРАЦИЙ;
5) АВАРИЙНЫЕ СИТУАЦИИ;
6) РЕКОМЕНДАЦИИ ПО ОСВОЕНИЮ.

Заполни содержимое КАЖДОГО из шести разделов для указанной программы,
строго соблюдая следующую структуру:

1. ВВЕДЕНИЕ:
   1.1. Область применения (1–2 предложения, где используется программа).
   1.2. Сокращения и обозначения (перечислить основные аббревиатуры,
        например, SAST, DAST, SCA, CVE, API, БД).
   1.3. Что умеет программа (краткий перечень 3–5 основных возможностей).

2. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ:
   2.1. Назначение программы (полное название, версия, разработчик,
        тип лицензии, назначение в 1–2 предложениях).
   2.2. Условия применения (системные требования) – оформить в виде
        перечня с подпунктами:
        – операционная система;
        – минимальный объём оперативной памяти;
        – свободное место на диске;
        – дополнительное программное обеспечение и зависимости;
        – поддерживаемое оборудование;
        – права доступа пользователя.

3. ПОДГОТОВКА К РАБОТЕ:
   3.1. Установка программы (пошаговые команды для Ubuntu через
        Docker/apt/snap, 5–7 шагов).
   3.2. Первоначальная настройка и первый запуск (создание учётной записи,
        вход в интерфейс, настройка языка, проверка работоспособности).
   3.3. Проверка работоспособности (создание тестового объекта).

4. ОПИСАНИЕ ОПЕРАЦИЙ:
   Составить 10–12 типичных операций, КАЖДУЮ оформить как отдельный
   подпункт с номером 4.x. Для каждой операции указать:
   – действие пользователя (что именно нажать, ввести, выбрать);
   – результат выполнения.
   Операции должны быть реальными для указанной программы, например:
   вход в систему, создание объекта, импорт данных, фильтрация,
   назначение ответственного, изменение статуса, генерация отчёта,
   добавление пользователя, экспорт через API, выход из системы.

5. АВАРИЙНЫЕ СИТУАЦИИ:
   Описать 5–6 ситуаций сбоев. Каждую оформить как подпункт 5.x, указав:
   – описание ситуации;
   – возможную причину;
   – действия пользователя для устранения.
   Обязательно включить: ошибку подключения к БД, неверный формат файла,
   потерю сессии, отказ контейнеров после перезагрузки, занятость порта,
   дублирование данных при импорте.

6. РЕКОМЕНДАЦИИ ПО ОСВОЕНИЮ:
   Дать 4–5 практических советов для обучения пользователей:
   – ссылка на официальную документацию;
   – создание тестового продукта для тренировки;
   – использование встроенных подсказок интерфейса;
   – последовательность действий для новичка;
   – рекомендация по изменению пароля администратора в промышленной среде.

ОФОРМЛЕНИЕ ПО ГОСТ:
– заголовки разделов (1, 2, 3, 4, 5, 6) писать ПРОПИСНЫМИ БУКВАМИ;
– подразделы (1.1, 1.2, 2.1, 2.2, 3.1, 3.2, 4.1, 4.2 и т.д.) – с заглавной,
  полужирным в оригинале, в текстовом варианте – начинать с новой строки;
– все команды терминала и названия файлов выделять отдельной строкой
  или кавычками;
– текст официально-деловым стилем, без разговорных выражений;
– не использовать markdown-таблицы – только текст с переносами строк,
  чтобы легко копировать в LibreOffice Writer;
– каждый раздел начинать с новой страницы (в тексте указать разрыв
  строки для вставки).

В ответе дай полностью готовый документ «Руководство пользователя»,
начиная с заголовка "РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ" и далее по разделам.
